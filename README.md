# CanchaYa-Grupo11
⚽ CanchaYA — Reserva tu cancha en segundos

CanchaYA es una aplicación móvil multiplataforma diseñada para conectar jugadores con complejos deportivos de forma rápida, intuitiva y sin complicaciones. Olvídate de las llamadas y mensajes sin respuesta: consulta disponibilidad en tiempo real, revisa el pronóstico del clima antes de jugar y asegura tu turno en pocos toques.

✨ Características principales:

Reserva rápida y calendario interactivo: Explora el catálogo de canchas con fotos y detalles, guarda tus favoritas y agenda tu horario al instante.

Ubicación y mapa del complejo: Encuentra fácilmente cómo llegar a cada recinto deportivo desde la app.

Clima integrado: Consulta las condiciones meteorológicas antes de confirmar tu partido.

Panel de Administración completo: Gestión de canchas, horarios, solicitudes de reserva, control de usuarios y reporte de ingresos en tiempo real.

🛠️ Stack Tecnológico:

Frontend Móvil: React Native + Expo

Backend & Base de Datos: Supabase (PostgreSQL + Auth)

Compilación: Expo Application Services (EAS Build — Android APK)
